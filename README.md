# חוות האפליקציות — כלי ניהול לבית הספר

חנות כלים דיגיטליים לניהול בית ספר. כל כלי עומד בפני עצמו — מנהלות ומנהלים בוחרים רק מה שהם צריכים.

## מבנה

- `index.html` — חזית החנות: קטגוריות, כרטיסי אפליקציות, סל
- `app.html?id=<app-id>` — דף פירוט לכל כלי
- `apps-data.js` — קטלוג הכלים (65 מערכות, 10 קטגוריות) — מבוסס על מערכת הניהול החיה (lerani.co.il/management)
- `store.js` — לוגיקת הסל, המגירה וטופס הליד
- `catalog-meta.js` — שכבת-מטא: הכוכבים (FEATURED), תגיות (חדש/מבוקש/AI), ערכות (BUNDLES), מפת-קשרים (LINKS), "יום בחיי מנהלת" (DAY), שאלון (QUIZ + recommend)
- `farm.js` — לוגיקת דף-הבית: סטטיסטיקות, יום-בחיי, כוכבים, חיפוש+סינון, קטלוג (flip בלחיצה, tilt ב-hover), שאלון "בנו את הסל", מצב-מצגת `?present=1`
- `style.css` — עיצוב משותף בשפה העיצובית של IMPACT OS (impactos.co.il): Heebo, navy `#061E4F` + fuchsia `#F00678` + teal `#12C7C7`, כפתורי pill, כרטיסים לבנים עם פס-צבע תחתון, פוטר navy
- `brand.js` — שכבת המותג והתנועה: סימן טביעת-אצבע+לב, לואדר, אור-עכבר ב-hero, badge בגלילה, reveal, flip במגע, מכתבת-פוטר
- `logos.js` — לוגו ייחודי לכל מערכת (זוג-גרדיאנט + סמל SVG מצויר ידנית). `logos-sheet.html` — גיליון לביקורת

כרטיסי הקטלוג הם flip-cards (כמו כרטיסי-המוצר באימפקט): קדמי = לוגו + שם, אחורי = תקציר, 3 יכולות, לסל, לפרטים. במחשב hover הופך; במגע — הקשה.

## לידים

טופס הסל שולח ל-CRM השיווקי המשותף (`sendLeadToCRM`, נטען מ-config.js של ריפו ort-training) עם `source: 'app-farm'`. יש גם קישור וואטסאפ ישיר עם רשימת הכלים שנבחרו.

## הוספת כלי חדש

מוסיפים אובייקט ל-`APPS` ב-`apps-data.js`: מזהה באנגלית, קטגוריה קיימת, שם, tagline (2-3 משפטים קצרים), תיאור, רשימת יכולות, וסמל SVG (תוכן פנימי של אלמנט svg בפורמט stroke — משמש כגיבוי).
ואז מוסיפים ל-`LOGOS` ב-`logos.js` מפתח לפי אותו id: `{ c1, c2, svg }` — שני צבעי-גרדיאנט וסמל לבן ב-viewBox 64×64. בלי לוגו — יוצג לוגו-ברירת-מחדל.
