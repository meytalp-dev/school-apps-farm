# חוות האפליקציות — כלי ניהול לבית הספר

חנות כלים דיגיטליים לניהול בית ספר. כל כלי עומד בפני עצמו — מנהלות ומנהלים בוחרים רק מה שהם צריכים.

## מבנה

- `index.html` — דף-הבית (נחיתה): hero, "יום בחיי מנהלת", הכוכבים, דמואים, אריחי-קטגוריות, מי-בנה, CTA. **בלי הקטלוג המלא** — הוא בדף נפרד
- `catalog.html` — הקטלוג המלא: חיפוש, צ׳יפים דביקים, כל המערכות לפי תחום. קישורים עמוקים: `?cat=<cat-id>` · `?q=<טקסט>` · `?present=1`
- `app.html?id=<app-id>` — דף פירוט לכל כלי
- `apps-data.js` — קטלוג הכלים (61 מערכות, 11 קטגוריות; 17.8 מוזגו כפילויות: roster→directory, group-broadcast→broadcast, planning-form→annual-plan, staff-calendar→calendar) — מבוסס על מערכת הניהול החיה (lerani.co.il/management)
- `store.js` — לוגיקת הסל, המגירה וטופס הליד
- `catalog-meta.js` — שכבת-מטא: הכוכבים (FEATURED), תגיות (חדש/מבוקש/AI), ערכות (BUNDLES), מפת-קשרים (LINKS), "יום בחיי מנהלת" (DAY), שאלון (QUIZ + recommend)
- `farm.js` — לוגיקה משותפת לשני הדפים (כל render בודק שהאלמנט קיים): סטטיסטיקות, יום-בחיי, כוכבים, דמואים, אריחי-קטגוריות (index) · חיפוש+סינון+URL-sync, קטלוג (flip בלחיצה, tilt ב-hover), שאלון "בנו את הסל", מצב-מצגת (catalog)
- `style.css` — עיצוב משותף בשפה העיצובית של IMPACT OS (impactos.co.il): Heebo, navy `#061E4F` + fuchsia `#F00678` + teal `#12C7C7`. **v5 (19.8) — שכבת "סטודיו" בסוף הקובץ, בשפת הסרטון (apps-farm-video):** נייר-משבצות + פריחות-פינה על כל הדף, תוויות-מקטע כסטיקרים-navy, קו-שרבוט מתחת למילה המודגשת (`<em>`), כרטיסים על נייר-נקודות עם סוגריים-פינה, תגיות כפתקים דביקים, hero דו-עמודי עם "שולחן-עבודה" (כרטיס-דפדפן + פתק + לב-קמע), דמואים כ-bento של כרטיסי-דפדפן, 4 שלבי-הליווי כפתקים. אין יותר לוגואי-גרדיאנט ולא משטחי-צבע רדיאליים.
- `brand.js` — שכבת המותג והתנועה: סימן טביעת-אצבע+לב, לואדר, אור-עכבר ב-hero, badge בגלילה, reveal, flip במגע, מכתבת-פוטר
- `logos.js` — **v5: מערכת-סימנים "סטודיו"** — `logoSVG()` מצייר לכל מערכת אריח-נייר בגוון-התחום + פס-סימון + גליף-דיו בקו אחיד (מ-`app.icon` ב-apps-data, או מ-`GLYPHS` — 38 גליפים ייעודיים למערכות שהיו עם placeholder). המילון `LOGOS` הישן (גרדיאנטים) נשמר לגיבוי בלבד. `logos-sheet.html` — גיליון לביקורת
- `assets/demos/*.jpg` — צילומי-מסך אמיתיים של 7 הדמואים (1280×800) — משמשים את כרטיסי-הדפדפן ב-hero, בסקשן הדמואים ובדף-הפירוט

כרטיסי הקטלוג הם flip-cards (כמו כרטיסי-המוצר באימפקט): קדמי = לוגו + שם, אחורי = תקציר, 3 יכולות, לסל, לפרטים. במחשב hover הופך; במגע — הקשה.

## לידים

טופס הסל שולח ל-CRM השיווקי המשותף (`sendLeadToCRM`, נטען מ-config.js של ריפו ort-training) עם `source: 'app-farm'`. יש גם קישור וואטסאפ ישיר עם רשימת הכלים שנבחרו.

## הוספת כלי חדש

מוסיפים אובייקט ל-`APPS` ב-`apps-data.js`: מזהה באנגלית, קטגוריה קיימת, שם, tagline (2-3 משפטים קצרים), תיאור, רשימת יכולות, וסמל SVG (תוכן פנימי של אלמנט svg בפורמט stroke — משמש כגיבוי).
ואז מוסיפים ל-`LOGOS` ב-`logos.js` מפתח לפי אותו id: `{ c1, c2, svg }` — שני צבעי-גרדיאנט וסמל לבן ב-viewBox 64×64. בלי לוגו — יוצג לוגו-ברירת-מחדל.

## דמואים חיים (`demo/`)

7 דמואים בעיצוב החווה עם נתוני-דמה של "בית ספר אימפקט" (`demo/demo-data.js`): פולס, תכנון משרות, לוח גאנט, שיחות מנהלת, גיוס משאבים, מחולל מודעות, ערכת מיתוג.
תשתית משותפת: `demo.css` (רכיבי-אפליקציה), `demo-shell.js` (סרגל-דמו, טוסט, מודאל, סוכן-AI מדומה), `BRIEF.md` (הכללים לבניית דמו חדש), `_template.html`.
רשימת הדמואים לחיווט בחווה: `DEMOS` ב-`catalog-meta.js` (סרט "דמו חי", כפתור "נסו עכשיו", סקשן דמואים).
🔴 אסור שום שם/נתון אמיתי בדמואים — רק DEMO.
