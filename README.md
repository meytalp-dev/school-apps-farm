# חוות האפליקציות — כלי ניהול לבית הספר

חנות כלים דיגיטליים לניהול בית ספר. כל כלי עומד בפני עצמו — מנהלות ומנהלים בוחרים רק מה שהם צריכים.

## מבנה

- `index.html` — חזית החנות: קטגוריות, כרטיסי אפליקציות, סל
- `app.html?id=<app-id>` — דף פירוט לכל כלי
- `apps-data.js` — קטלוג הכלים (24 כלים, 5 קטגוריות, סמלי SVG)
- `store.js` — לוגיקת הסל, המגירה וטופס הליד
- `style.css` — עיצוב משותף (בהיר, Playpen Sans Hebrew + Assistant)

## לידים

טופס הסל שולח ל-CRM השיווקי המשותף (`sendLeadToCRM`, נטען מ-config.js של ריפו ort-presentation-builder) עם `source: 'app-farm'`. יש גם קישור וואטסאפ ישיר עם רשימת הכלים שנבחרו.

## הוספת כלי חדש

מוסיפים אובייקט ל-`APPS` ב-`apps-data.js`: מזהה באנגלית, קטגוריה קיימת, שם, tagline (2-3 משפטים קצרים), תיאור, רשימת יכולות, וסמל SVG (תוכן פנימי של אלמנט svg בפורמט stroke).
